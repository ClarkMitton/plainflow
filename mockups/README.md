# Mockups

Static HTML, open in a browser. Drawn on a design canvas at 1400 by 820 and converted, so expect small overlaps. They are references for layout and style, not pixel specs. Fonts load from Google Fonts.

| File | What it shows |
| --- | --- |
| Master.html | A5, flow first. The main canvas with the paperwork rail and readout. Reproduce this first. |
| TierFirst.html | A5, tier first. Tier picker, constrained palette, a blocked wire with two ways out. |
| CompanyCard.html | A5, a company node opened: role, Article 28 clauses, sub-processors, status, open actions, reuse. |
| Compare.html | A5, pin A / try B with deltas in the middle. |
| PaperA5.html | The chosen theme on the original single-canvas layout. |
| PaperTypes.html | Colour by node type on the plain Paper theme, which A5 inherited. |
| Paper.html | The base Paper theme without family colour. |
| Transit.html, Rack.html | Two rejected concepts kept for reference: a transit-map metaphor and a modular-synth metaphor. |
